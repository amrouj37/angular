# Gestion des conférences - Angular

Prosits Angular (Esprit 2026/2027).

- Prosit 1 : notion de composant -> `/profil`
- Prosit 2 : data binding et signals -> `/detail-conference`
- Prosit 3 : directives, contrôle de flux et pipes -> `/conferences`
- Prosit 4 : communication entre composants -> `/communication`
- Prosit 5 : HttpClient et web services (json-server) -> `/api-conferences`

Les comptes rendus sont dans le dossier `docs`.

## Lancer le projet

```bash
npm install
npm run api   # backend json-server (port 3000), nécessaire pour le prosit 5
ng serve      # dans un autre terminal
```

Puis ouvrir http://localhost:4200
